# Resume patterns

Defects worth not repeating. `/job` appends here when a build goes wrong in a way that would
recur, and reads it before writing bullets.

Start empty. Add an entry when you catch something in a rendered resume that the writing rules
did not already prevent — a bullet that read twice, a number that crept upward, a section that
overflowed the page.

## Format

**What went wrong** — where it appeared, and what it should have been instead.
