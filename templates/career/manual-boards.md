# Manual boards

Companies worth watching by hand, because they are not on Greenhouse, Lever, or Ashby and so
`scan.py` cannot reach them. `/job` reads this file and checks each row on its stated cadence.

The mechanics — how to check one, how to log it, when to change a cadence — live in the skill's
`references/manual-boards.md`. This file is just the list.

**Cadence** is one of `Weekly`, `Monthly`, `Quarterly`. Choose it by how fast the board actually
moves, not by how much you want the job.
