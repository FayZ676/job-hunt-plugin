# Employer accounts

Some application systems — Workday above all — require an account per employer before they will
show you a form. This file is the index of which ones you have.

**Do not put passwords here.** Store them in your password manager and record only the pointer, so
this file staying in a synced vault is harmless. `/job` will never invent a password: if it needs
one and finds no entry, it stops and asks.

| Employer | System | Login email | Where the password lives | Created |
| -------- | ------ | ----------- | ------------------------ | ------- |
| Example Corp | Workday | you@example.com | 1Password → "Example Corp careers" | 2026-08-01 |

Activation links are usually single-use: once you have clicked one, opening it again returns an
error rather than logging you in. Record the account here as soon as it exists.
