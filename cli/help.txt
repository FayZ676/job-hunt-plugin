job — search every company career site, score the openings, tailor a resume,
      stage the application, and submit what you approve.

usage: /job [command] [argument]

commands:
  (none)                      run all five phases: search, score, resume, stage, submit
  setup                       first-run setup: create $CAREER, build the profile, set the filters
  search                      search and rule only
  score [key]                 score the prospects already found
  resume [JD, URL, or key]    tailor a resume for every shortlisted role
  apply [key or URL]          stage every shortlisted application, stopping before submit
  submit [key]                review what is staged and submit only what you name
  ui                          serve the dashboard on 127.0.0.1:8765; run the phases and edit your profile there
  help                        this message

notes:
  run `/job setup` first — every other command is a no-op until $CAREER exists
  nothing is submitted without your approval, named by you, in that run
  a field your profile does not answer is left empty and reported, never guessed
  everything lives in $CAREER/job.db (default ~/data/job, JOB_CAREER_DIR overrides)
  searching costs Apify credit, billed per job returned — ruling again is free
  ask about your search in plain English — it is answered with a query
